# peterbulloch.dev

A static portfolio website for Peter Bulloch, available in English and Korean. It includes a light/dark theme toggle and is built with plain HTML, CSS, and JavaScript; there is no build step or package installation.

## Preview locally

Open `public/index.html` in a browser.

## Project structure

- `public/` - Website pages, styles, scripts, and assets.
- `.github/workflows/deploy.yml` - Deploys the contents of `public/` to the web server when changes are pushed to `main`.
